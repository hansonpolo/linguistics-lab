# 语言学 · 研习台

《语言学概论》课程的本地优先学习与复习工作台。单用户、自托管、数据全部落在本机的一个 SQLite 文件里，不联网也能完整使用（AI 除外，且 AI 是可选的）。

界面走「纸本 + 朱砂」的学术阅读风格，默认夜读暗色，另备纸本亮色；长文按中文书籍的行距与标点规则排版，公式用 KaTeX 内联渲染。

---

## 一、五大板块

### 1. 结构化知识库
- 十二章、二十四篇笔记，遵循叶蜚声、徐通锵《语言学纲要》的章节脉络；侧栏按章索引，可搜索、按章筛选、按标签筛选。
- 笔记支持 Markdown 正文、`$…$` / `$$…$$` 公式、`[^1]` 脚注、`[[n08]]` 笔记互链、`[[概念:音位]]` 概念链、`> ` 摘录块，以及 GB/T 7714 参考文献列表。
- 阅读页右侧常驻：本篇目录、牵涉概念、反向链接、关联闪卡、摘录批注；选中正文任意一句即可「摘录 / 制卡」。
- 知识图谱用 canvas 力导向布局，包含 `包含 / 对立 / 影响 / 相关` 四类关系，可切换关系类型、按章过滤、拖拽缩放，点节点看定义与出处笔记。

### 2. FSRS 间隔重复
- 自研 FSRS-5 调度器（`server/lib/fsrs.js`），19 个默认参数、四档评分、学习步 1min / 10min，按保留率换算间隔。
- 卡片类型：问答、填空（`{{c1::…}}`）、辨析、图片。翻面前填空只显示下划线，翻面后高亮答案。
- 复习页显示每档评分的下次间隔，键盘 `空格` 翻面、`1–4` 评分、`Esc` 退出。
- 仪表盘含掌握率、30 天保持率、连续打卡、复习热力图、未来两周到期预测、章节推进与「易忘卡片」。
- 答错的卡片与题目自动进入错题本，并绑定章节笔记与知识点。

### 3. 自测题库
- 40 道种子题：单选 16、判断 8、名词解释 6、简答 6、材料分析 4，均带踩分点与解析。
- 组卷支持「练习卷 / 模拟套卷」，按章节、题型、数量、限时自由配置；模拟卷带倒计时，归零自动交卷。
- 主观题作答后先「对照参考答案」，再按五档自评（1 / 0.75 / 0.5 / 0.25 / 0）折算得分。
- 交卷后给出总分、题型得分率、逐题对错与解析；历史记录可回看。
- AI 出题只产草稿，必须勾选后手动入库，符合「人工审核」的要求。

### 4. AI 学习助手
- **答疑 / 辨析**：回答固定分三段——【教材主流结论】【学界争议观点】【小众假说】，每段都挂着出处笔记与概念链接；没有证据时明说「教材未涉及」，不编造。
- **背诵抽查**：从笔记里抽题，按踩分点关键词覆盖率 + 篇幅完整度打分，列出命中的点与遗漏的点。
- **提取考点**：粘贴 PPT 文字或选一篇笔记，产出提纲、术语、考点与闪卡/题目草稿。
- 默认完全本地运行（检索 + 规则拼接，不需要任何 API Key）；在「工具 → 设置」里填 OpenAI 兼容的 `base_url / model / key` 后，会自动追加一段大模型生成的补充说明，失败则静默回退本地结果。也可用环境变量 `AI_BASE_URL / AI_MODEL / AI_KEY` 配置。

### 5. 语言学工具
- **IPA 面板**：按发音部位分组的辅音、元音与附加符号，点选插入、一键复制。
- **参考文献**：按 GB/T 7714-2015 生成专著、期刊、学位论文、析出文献、报告、标准、报纸、网络资源条目，>3 位作者自动加「等」。
- **设置**：目标保留率（0.8–0.97）、每日新卡/复习上限、每日目标分钟、套卷时长、主题、AI 配置。
- **数据**：导出全部 JSON、卡片 CSV、SQLite 文件本身；导入 JSON 备份或 CSV 卡片。
- **PWA**：手写 Service Worker，离线打开外壳与已访问页面；静态资源 cache-first，接口 network-first 并带离线兜底。

## 二、运行

### 环境要求
- Node.js **≥ 22.5**（用到内置 `node:sqlite`；推荐 22 LTS 或 24）
- 无任何原生依赖，不需要编译工具链

### 开发模式
```bash
npm install
npm run dev          # 同时起 API(8787) 与 Vite(5173)
```
打开 http://127.0.0.1:5173 ，前端已把 `/api` 代理到 8787。

### 生产模式（单端口）
```bash
npm install
npm run build        # 产物在 dist/
npm start            # http://127.0.0.1:8787
```
`npm start` 会把 `dist/` 与 API 挂在同一个端口上，SPA 路由自动回退到 `index.html`。

> 构建脚本说明：`npm run build` 走 `build.mjs`（Vite JS API 进程内构建），在没有子进程权限的受限沙箱里也能出包；普通环境也可以用 `npm run build:vite` 调官方 CLI。

### Docker
```bash
docker compose up -d --build
# 打开 http://127.0.0.1:8787 ，数据落在 ./data/lingua.db
```

### 端口与数据目录
| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | 服务端口 |
| `HOST` | `127.0.0.1` | 监听地址；Docker 里设为 `0.0.0.0` |
| `DATA_DIR` | `./data` | SQLite 与备份所在目录 |

## 三、种子数据与重置

首次启动会自动播种（12 章 / 24 篇笔记 / 42 个概念 / 60 张卡 / 40 道题）。手动重置：

```bash
npm run seed -- --force
```

种子数据在 `server/seed/`，格式见 `server/seed/SCHEMA.md`；改完 JSON 重跑上面的命令即可。也可以直接删掉 `data/` 目录，下次启动会重新播种。

---

## 四、备份与迁移

- 「工具 → 数据」里可导出 `all / notes / cards / questions` 四类 JSON，以及卡片 CSV。
- `GET /api/backup/file` 直接下载 SQLite 数据库文件，复制 `data/lingua.db`（连同 `-wal`、`-shm`）就是完整备份。
- 导入 JSON 备份会按 id 合并，不会清空已有内容。

## 七、已知边界

- AI 的默认引擎是本地检索拼接，回答质量取决于笔记内容；接入大模型后才会出现成段的自然语言解释。
- 目前只支持 CSV / JSON 卡片导入，Anki 的 `.apkg` 需要先转成 CSV。
- PWA 的 Service Worker 仅在 `localhost` 或 HTTPS 下注册，局域网 IP 访问时不会启用离线。
- 界面按单用户设计，没有账号、权限与公网分享功能——这是刻意的取舍。
